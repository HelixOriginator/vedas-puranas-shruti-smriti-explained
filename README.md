# Principle & Expression — Shruti, Smriti, and the Shape of an Answer

A single-page, dark-mode explainer that answers three public questions about Sanatana Dharma by tracing where timeless Vedic principle (Shruti) ends and lived Puranic story (Smriti) begins.

## What this covers

1. **Vedas vs. Puranas** — why a tradition needs both the law (Siddhanta) and the story (Drishtanta), with a side-by-side comparison table and a "recipe vs. meal" analogy.
2. **"If the Vedas know everything, why no dinosaurs?"** — separating universal metaphysical principle from time- and place-bound iconography, with a physics analogy.
3. **"If God is in everyone, what about evil?"** — the *asanga* (unattached) argument, the light-through-dirty-water analogy, and how karma does the accounting instead of direct intervention.

Each section closes with a short, plain-language takeaway, and the page ends with a set of related essays and frameworks on governance, research taxonomy, and dharmic AI.

## Tech

- Single static file: `index.html`
- No build step, no dependencies beyond two Google Fonts (Fraunces, Karla)
- Fully self-contained CSS (custom properties for theming), one small inline SVG animation, `prefers-reduced-motion` respected
- Deployable as-is on GitHub Pages, Netlify, or any static host
