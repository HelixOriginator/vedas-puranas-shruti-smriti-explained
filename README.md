# vedas-puranas-shruti-smriti-explained
A dark-mode explainer on Sanatana Dharma answering three public questions: how Vedas and Puranas work together, why the Vedas don't mention dinosaurs, and how God can be present in evil without being tainted by it. Covers Shruti-Smriti philosophy, analogies, and related governance and research links by Kallol Chakrabarti.
